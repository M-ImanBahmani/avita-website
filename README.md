Avita Software Group — Corporate Website (گروه نرم‌افزاری آویتا)

A modern, responsive, RTL Persian corporate landing page designed and developed for Avita Software Group using pure HTML5, CSS3, and jQuery.

🔗 View Live Demo

✨ Key Features

Full RTL Support: Built specifically for Persian typography using IranYekan and Pinar custom webfonts.

Interactive Full-Screen Overlay Menu: Smooth animated navigation drawer with custom hover transitions.

Animated Hero Section: Subtle zoom background effect paired with a custom-styled RTL search bar.

Services & Statistics Showcase: Interactive service cards with 3D icon flip effects and a parallax counter section.

Portfolio Gallery: CSS Grid-based portfolio section with category filters and hover overlays.

Team & Testimonials: Responsive customer reviews and team member cards with animated social media menus.

Contact Form & Footer: Clean contact section with custom focus states, quick links, tags, and app download badges.

🛠️ Technologies Used

HTML5 (Semantic Markup)

CSS3 (Flexbox, CSS Grid, Custom Properties, Keyframe Animations, Responsive Media Queries)

jQuery 3.7.1 (DOM Manipulation & Overlay Menu Interactions)

FontAwesome (UI & Brand Icons)

Normalize.css (Cross-browser Consistency)
